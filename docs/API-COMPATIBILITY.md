# Telegram Bot API compatibility

UltraTelegram uses a generic method-forwarding client instead of maintaining a generated PHP method for every Telegram endpoint.

## Calling methods

Every Bot API method can be called through `TelegramClient::call()` or the dynamic method interface:

```php
$bot->call('sendMessage', [
    'chat_id' => 123456789,
    'text' => 'Hello'
]);

$bot->sendMessage(
    chat_id: 123456789,
    text: 'Hello'
);
```

The client validates the method name format, serializes the supplied parameters, selects JSON or multipart encoding, disables redirects on token-bearing requests, and parses Telegram's standard response envelope. Telegram remains responsible for validating whether a particular method exists and whether its parameters satisfy the current schema.

## Version baseline

The documented compatibility baseline is Telegram Bot API 10.3 (August 24, 2026). The generic method interface also forwards method names and parameter fields added after this baseline, but it does not provide compile-time validation or generated typed parameter classes for new fields.

## Update types

`TelegramUpdate::getUpdateType()` recognises the update event fields documented through Bot API 10.3, including business, guest-message, managed-bot, subscription and stopped-message-generation updates. Unknown future update fields are still returned by the generic fallback when the update contains one event payload.

## Upload rules

An `InputFile` can be supplied as a top-level method parameter or nested inside arrays and `JsonSerializable` objects. Nested files become `attach://` references and are added to the same multipart request. API methods that accept a file upload must use POST.

## Transport rules

- POST with JSON is the default.
- GET is available through `call($method, $parameters, 'GET')`.
- File uploads use multipart/form-data generated by PHP cURL.
- API calls and file downloads do not follow redirects because the bot token is part of the request URL.
- `callMany()` requires a transport implementing `ConcurrentTransportInterface` and delegates to Ultra Request's concurrent executor.
- Long polling and webhook delivery are mutually exclusive at Telegram's side; choose one update delivery mode.

For the complete and current parameter schema, use Telegram's official documentation: <https://core.telegram.org/bots/api>.
